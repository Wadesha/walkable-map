关于「数据写死 / 省资源」

专题是静态的 → 离线算一次,把每站 2km 网格存成静态 JSON/瓦片。网页只加载正在看的那个站(约 150–200 格 ≈ 几 KB),所以不管总共有 1 万还是 100 万站,单次访问内存都极小。

难点在于「算出来」(OSM 路网 + DEM + POI,离线批处理),不在「写死」。百万级站点 GitHub Pages 放不下,生产应用 PMTiles/矢量瓦片 + 分片存储,网页只加载瓦片即可秒开。

演示里为自包含,网格在浏览器按种子即时生成;生产只需把 buildGrid() 换成 fetch('data/'+id+'.json')(预生成的静态文件)。
